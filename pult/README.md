# Пульт — GTD-админка

Личный дашборд задач, проектов, целей и конспектов на `ivanilin.ru/pult`.
Статическая страница без бэкенда: работает на GitHub Pages, ставится на телефон
как приложение, открывается офлайн.

## Как это устроено

Главное решение интерфейса: **у задачи нет ни модалки, ни боковой панели** —
строка раскрывается на месте. Поэтому взаимодействие на десктопе и на телефоне
буквально одинаковое, и привычка переносится с устройства на устройство.

Меняется только обёртка вокруг одного и того же списка:

| | Десктоп (≥900px) | Телефон (<900px) |
| --- | --- | --- |
| Навигация | боковое меню со счётчиками | нижний таб-бар на 5 разделов + «Ещё» |
| Управление | клавиатура: `↑` `↓` `Space` `Enter` `N` | свайпы по строке, кнопка захвата под большим пальцем |
| Задача | раскрывается в строке | раскрывается в строке |

Свайп вправо — выполнить, влево — перенести на завтра.

## Разделы

| Раздел | Зачем |
| --- | --- |
| **Сегодня** | Рабочий экран: просрочено, на сегодня, что двигает главную цель |
| **Скоркард** | Состояние системы за неделю + лесенка Top Goal и полоса за 14 дней |
| **Ревью** | Чеклист еженедельного обзора с живыми счётчиками по каждому шагу |
| **Инбокс** | Захвачено, но ещё не разобрано |
| **Next actions** | Действия по контекстам: @комп, @звонки, @смартфон, @дом, @город |
| **Ожидание** | Делегированное; висящее дольше недели подсвечивается |
| **Agenda** | Вопросы к людям, сгруппированные по адресату |
| **Когда-нибудь** | Идеи вне текущих обязательств |
| **Проекты** | Где больше одного шага; проект без next action помечается красным |
| **Цели** | Горизонт выше проектов, одна помечается главной |
| **Конспекты** | Записи звонков; строки-действия извлекаются в задачи одной кнопкой |
| **SEO-пайплайн** | Ваша страница пайплайна, встроенная в пульт по указанному адресу |
| **Боты и Make** | Отправка заданий во внешний сценарий по вебхуку |
| **Данные** | Экспорт/импорт JSON, синхронизация с `todo.md`, тема, очистка |

## Строка захвата

Одна строка — одна задача:

```
Позвонить Пете по смете @звонки #Ремонт_офиса !завтра *
```

| Маркер | Смысл |
| --- | --- |
| `@звонки` | контекст: `@комп`, `@звонки`, `@смартфон`, `@дом`, `@город`, `@везде` |
| `#Проект` | проект (создаётся, если такого нет; `_` превращается в пробел) |
| `!завтра` | срок: `сегодня`, `завтра`, `вчера`, `пн`…`вс`, `12.09`, `2026-09-12` |
| `?Петя` или `? ` | в «Ожидание» |
| `>Петя` или `> ` | в «Agenda» |
| `~` | в «Когда-нибудь» |
| `+30м`, `+2ч` | оценка времени |
| `*` | действие работает на главную цель |

В конспектах те же правила действуют построчно: строки с `-`, `?` или `>`
превращаются в задачи по кнопке «Извлечь действия».

## Синхронизация с todo.md

Пульт читает и пишет обычный Markdown, поэтому его можно держать в паре с любым
файлом задач. В разделе «Данные» вставляете содержимое `todo.md` и жмёте «Влить
в пульт»: добавятся только недостающие строки, повторное вливание того же файла
дублей не создаёт. Обратно — «Скачать todo.md».

Формат — тот же синтаксис, что и в строке захвата:

```markdown
## Next actions

- [ ] Собрать отчёт @комп +45м

### Ремонт офиса
- [ ] Позвонить Пете по смете @звонки #Ремонт_офиса !2026-09-01 *

## Ожидание

- [ ] пришлёт договор ?Аня
```

Заголовок `##` задаёт список, `###` — проект, `- [x]` — выполненное. Всё, что
не разобралось, попадает в инбокс, а не теряется.

## Где лежат данные

В `localStorage` браузера. На сервер ничего не уходит, поэтому конспекты звонков
не увидит тот, кто просто откроет адрес. Обратная сторона — телефон и ноутбук не
синхронизируются автоматически: переносите файлом через «Данные».

Ключ хранилища: `ivanilin.gtd.v1`.

## Интеграция наружу

Раздел «Боты и Make» шлёт `POST` на заданный вебхук (Custom webhook в Make, n8n
или свой обработчик). Заголовок `Content-Type: text/plain`, чтобы браузер не
делал CORS-preflight; тело — JSON:

```json
{
  "event": "bot.create",
  "token": "если задан в настройках",
  "payload": {
    "name": "Бот-квалификатор лидов",
    "brief": "что делает и куда пишет результат",
    "channel": "Telegram",
    "model": "claude-sonnet-5",
    "requestedAt": "2026-08-31T09:00:00.000Z",
    "requestId": "..."
  }
}
```

События: `ping` — проверка связи, `bot.create` — заявка на бота (одновременно
заводит строку в «Ожидании»), `task.send` — отправка задачи из раскрытой строки.
Пока URL вебхука не задан, кнопки «Отправить в Make» никуда не отправляют и
пишут об этом в журнал.

## SEO-пайплайн

Раздел встраивает вашу существующую страницу пайплайна по адресу из настроек.
Если она лежит рядом в репозитории по адресу `/seo-status/`,
хватит относительного пути — он подставлен по умолчанию.

## Файлы

```
pult/
├── index.html              оболочка
├── manifest.webmanifest    установка на домашний экран
├── sw.js                   офлайн-кэш (network-first)
└── assets/
    ├── app.css             оформление и адаптив
    ├── store.js            модель данных, localStorage, срезы, вебхук
    ├── parse.js            разбор строки захвата
    ├── markdown.js         чтение и запись todo.md
    └── app.js              рендер, роутер, обработчики
```

Сборки нет — это ES-модули, которые браузер грузит напрямую. Локально:
`npx http-server -p 8899` и открыть `http://127.0.0.1:8899/pult/`.
