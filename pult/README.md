# Пульт — GTD-админка

Личный дашборд задач, проектов, целей и конспектов на `ivanilin.ru/pult`.
Статическая страница без бэкенда: работает на GitHub Pages, ставится на телефон
как приложение, открывается офлайн.

## Разделы

| Раздел | Зачем |
| --- | --- |
| **Дашборд** | Скоркард недели + счётчик Top Goal с таймером и лесенкой 30→45→60→90→120 мин |
| **Ревью** | Чеклист еженедельного обзора с живыми счётчиками по каждому пункту |
| **Инбокс** | Всё, что захвачено и ещё не разобрано |
| **Next actions** | Действия, сгруппированные по контекстам: @комп, @звонки, @смартфон, @дом, @город |
| **Ожидание** | Делегированное; строки старше 7 дней подсвечиваются |
| **Agenda** | Вопросы к людям, сгруппированные по адресату |
| **Когда-нибудь** | Идеи вне текущих обязательств |
| **Проекты** | Всё, где больше одного шага. Проект без next action помечается красным |
| **Цели** | Горизонты выше проектов, одна помечается главной — на неё работает Top Goal |
| **Конспекты** | Записи звонков и архив Майка одним списком: открываются на чтение с разметкой, правятся по кнопке. Строки-действия извлекаются в задачи |
| **SEO-пайплайн** | Ваша страница пайплайна, встроенная в пульт по указанному адресу |
| **Агенты** | Майк (главный) и вебхук-агенты: задачи, конспекты и поручения — наружу |
| **Данные** | Экспорт/импорт JSON, синхронизация с `todo.md` (в т.ч. подтягивание задач от Майка), тема, очистка |

## Строка захвата

Одна строка — одна задача. Синтаксис разбирается автоматически:

```
Позвонить Пете по смете @звонки #Ремонт_офиса !завтра *
```

| Маркер | Смысл |
| --- | --- |
| `@звонки` | контекст: `@комп`, `@звонки`, `@смартфон`, `@дом`, `@город`, `@везде` |
| `#Проект` | проект (создаётся, если такого нет; `_` превращается в пробел) |
| `!завтра` | срок: `сегодня`, `завтра`, `вчера`, `пн`…`вс`, `12.09`, `2026-09-12` |
| `?Петя` или `? ` | в «Ожидание» |
| `>Петя` или `> ` | в «Agenda» |
| `~` | в «Когда-нибудь» |
| `+30м`, `+2ч` | оценка времени |
| `*` | действие работает на главную цель |

В конспектах те же правила действуют построчно: строки, начинающиеся с `-`, `?`
или `>`, превращаются в задачи по кнопке «Извлечь действия».

Горячие клавиши: `N` — фокус в строку захвата, `Esc` — закрыть панель.

## Синхронизация с todo.md

Пульт читает и пишет обычный Markdown. В разделе «Данные» вставляете содержимое
`todo.md` и жмёте «Влить в пульт»: добавятся только недостающие строки,
повторное вливание того же файла дублей не создаёт. Обратно — «Скачать todo.md».
Заголовок `##` задаёт список, `###` — проект, `- [x]` — выполненное; контексты,
проекты, сроки и звёздочка главной цели переживают круг туда-обратно.

## SEO-пайплайн

Раздел встраивает вашу существующую страницу пайплайна по адресу из настроек.
По умолчанию подставлен `/seo-status/`.

## Где лежат данные

В SQLite на сервере — `/var/lib/pult/pult.db`, за тем же токеном, что и мост
Майка. Телефон и ноутбук видят одно и то же; ночью база копируется в
`/var/backups/pult` (14 копий).

`localStorage` (ключ `ivanilin.gtd.v1`) остался офлайн-кешем: без сети пульт
открывается и пишет, правки уезжают, когда связь вернётся. Порядок правок
разводится по номеру ревизии, а не по времени — часы у устройств разные.
Значок в шапке показывает состояние: «на сервере», «N в очереди», «нет связи».

**Пока токен Майка не задан, сервер не используется вообще** — пульт работает
как раньше, только в этом браузере. Токен хранится локально и на сервер в
составе данных не уходит, поэтому вводится на каждом устройстве один раз.

Сервис: `pult-api.service` (127.0.0.1:8901), код — `/srv/pult/api.py`,
`nginx` отдаёт его на `/pult/api/`.

## Агенты

Главный агент — **Майк** (hermes-агент на том же сервере, что и сайт). Пульт
говорит с ним через мост `/mike/` на этом же домене, поэтому CORS не нужен.
В настройках раздела «Агенты» ему требуется только токен моста — он лежит на
сервере в `/root/.hermes/pult-token.txt` и отзывается одной строкой в
`/etc/nginx/conf.d/mike-bridge-auth.conf`.

Потоки с Майком:

| Поток | Куда | Как |
| --- | --- | --- |
| Задача → Майку | панель задачи, «⚡ Отправить Майку» | сообщение в чат `/mike/v1/chat/completions`, Майк заводит её у себя |
| Конспекты ↔ Майка | автоматически | `konspekty/*.md` и записи пульта — один пул: правка файла едет в пульт, правка записи — обратно в файл. Новая запись получает свой файл |
| Конспект → Майку | открытый конспект, «⚡ Майку» | отдельно попросить Майка посмотреть запись |
| Поручение | раздел «Агенты» | свободный текст + строка в «Ожидании» |
| Задачи ↔ Майка | автоматически | его `TODO.md` и база пульта — одно и то же: скажете Майку задачу в Telegram, он пишет её в файл, и она появляется в пульте; закроете в пульте — у него встаёт галочка |
| Задачи ← Майка | «Данные → ← Задачи от Майка» | разовое вливание вручную, если автосинхронизация выключена (нет токена) |

Ответ Майка на каждую отправку виден в журнале раздела.

Остальные агенты — вебхуки (n8n, свой обработчик): `POST` с
`Content-Type: text/plain` (чтобы не было CORS-preflight), тело —
`{ "event", "token", "payload" }`. События: `ping`, `task.send`, `errand`.

## Файлы

```
pult/
├── index.html              оболочка
├── manifest.webmanifest    установка на домашний экран
├── sw.js                   офлайн-кэш (network-first)
└── assets/
    ├── app.css             оформление и адаптив
    ├── store.js            модель данных, localStorage, срезы, вебхук
    ├── parse.js            разбор строки захвата
    └── app.js              рендер, роутер, обработчики
```

Сборки нет — это ES-модули, которые браузер грузит напрямую. Локально:
`npx http-server -p 8899` и открыть `http://127.0.0.1:8899/pult/`.
